Enhanced visual design and UX improvements for better readability and user experience:

- **Refined card styling**: Deeper shadows, more polished borders, better spacing
- **Enhanced form inputs**: Larger padding, improved focus states, better visual feedback on hover
- **Improved table design**: 
  - Alternating row backgrounds for better readability
  - Enhanced header styling with gradient background

- **Better visual hierarchy**: 
  - Stronger typography contrasts

  - More generous spacing throughout
- **Polished estimate hero**: Enhanced gradient with radial shine effect

- Refined border styling (1.5px borders instead of 1px)
- Better gradient overlays for visual interest
